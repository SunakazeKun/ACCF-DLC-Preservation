# Indices
Each distributed pattern or letter includes an incremental index. When downloading DLC, the game compares this value 
to the previously installed index. For new save files, these recorded indices start at 0. Data is installed only if 
its index is different from the current record whereas equal values are rejected. As the releases varied by region, 
the table below lists these indices and the associated content by region. The indices were inferred from dumped 
WiiConnect24 and letter data. Extrapolated indices derived from gap patterns and known release dates are unconfirmed 
and marked in parentheses.
